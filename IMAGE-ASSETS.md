# Workspace imagery

Original images created using the built-in imagegen tool for this portfolio. Converted to local WebP assets with Pillow; no remote image dependencies.

- `public/images/workspace.webp`: 1536 x 1024 hero and services background.
- `public/images/workspace-960.webp`: 960 x 640 mobile hero variant.
- `public/images/workspace-detail.webp`: 1200 x 800 About and Contact background.

## Hero prompt

Create an original photorealistic cinematic website hero background, landscape 3:2. An elegant developer workspace at night, near-black charcoal room and subtle mauve/purple ambient light. Composition: left 45 percent almost black atmospheric negative space for readable HTML heading; right side a beautifully detailed open laptop angled toward viewer with a believable code editor, dark wooden desk, matte mauve ceramic mug, stacked blank books and a small leafy plant; tall monitor and softly purple-lit wall in background. Sophisticated editorial photography, realistic materials, restrained lighting, deep shadows, soft dusty pink highlights, no neon RGB, no haze blobs. Absolutely no humans, faces, hands, portraits, silhouettes or human reflections. No logos, watermark or typography overlays. This is a photographic background asset only, not a website mockup.

Elegant violet and dusty pink ambient light on charcoal textured wall. Composition has objects on right two thirds; left is deep shadow blending toward black for use with text overlay. Cinematic natural photographic detail and restrained rich plum palette, no RGB gaming lighting. No text overlays or logos. Absolutely no people, human figures, hands, faces, silhouettes, portraits or reflections of people. No illustrations. Clean realistic desk accessories, sophisticated warm atmosphere.
